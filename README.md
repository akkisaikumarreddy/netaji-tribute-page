# netaji-tribute-page
A clean, responsive 2-page tribute website dedicated to Netaji Subhas Chandra Bose, built using semantic HTML5 and custom CSS3.

---

## 🌟 Features

* **Two-Page Layout:** Structured like clean A4 poster sheets with built-in page indicators.
* **Balanced Content:** Features historical background, key milestones, and iconic quotes across both pages.
* **Responsive Design:** Looks clean and structured on desktops, tablets, and mobile devices.
* **Print & PDF Ready:** Includes a dedicated `@media print` stylesheet that formats the layout for clean physical printing or PDF export without wasting ink.
* **Semantic Code:** Built using clean HTML5 structures and custom CSS3 without external heavy framework dependencies.

---

## 🛠️ Tech Stack

* **HTML5** — Document structure and semantic tagging
* **CSS3** — Custom styling, Flexbox layout, gradients, and `@media print` optimizations
